分享一个颜值超高的终端音乐播放器：[rmpc](https://github.com/mierak/rmpc)。我把听歌从 Spotify 搬进了终端，开一个 tab 就是整个播放器，最直接的感受是：不再有广告了。

换之前我也试过别的。Apple Music 要付费，音质很高，但曲库不全；QQ 音乐和网易云音乐是国内主流，可 VIP 上面有 SVIP，SVIP 上面还有单曲购买，很无语。后来和找 Yazi 时一样，主动去搜终端播放器，看了 B 站、小红书和 AI 的推荐，搜到 rmpc 之后对它最满意，现在听歌只用它。

![真实桌面操作：页面切换、搜索切歌、五种菜单栏布局里的歌词位置与主题联动](/media/rmpc/rmpc-zh.mp4)

## 颜值超高，布局随便改

我的主页面左边是播放队列，右边是正方形的专辑封面，封面下面是跟着音乐跳动的频谱。布局完全可以自定义，哪块放什么、占多大，都写在配置里。

换桌面主题时，播放器的配色也会跟着一起变，不用单独再调。

## 一分钟上手

rmpc 只有四个页面：播放队列、歌手、歌单和搜索，按数字 `1` 到 `4` 切换。1 分钟就能上手。

操作用的是 Vim 键位，也就是沿用 Vim 文本编辑器的键盘习惯：`j`、`k` 上下移动，`/` 搜索，空格多选，`p` 暂停，`<`、`>` 切上一首、下一首。这套键位和我用的 Yazi、dooit 是统一的，换工具不用换手感。

平时它就待在终端的一个 tab 里，摸鱼的时候切过去就行。

## 想听什么，一句话交给 Agent

rmpc 放的是本地曲库，所以资源很丰富：网络上只要有的，都能导入歌单，不存在找不到的歌。

找资源和导入我都交给 AI Agent，一句话就搞定。效率高，成本也很低，这种简单任务用小模型就够了。

## 歌词就在菜单栏

正在播放的歌词会一行一行滚动显示在我配置的菜单栏里，切到别的窗口也看得到。

rmpc 还能接电台：没有具体曲目，24 小时连续播放，切歌就是切电台。我试过一阵，现在已经不用了，但想要的话是有的。

## 配置可以单独取用

rmpc 只是界面，真正放歌的是后台的 MPD（Music Player Daemon，一个常驻的音乐播放服务），关掉 rmpc 歌也不会停。配置放在 [Asaki14/dotfiles](https://github.com/Asaki14/dotfiles) 的 `rmpc/`、`mpd/` 和 `beets/` 目录，适用于 macOS，需要先装好 Homebrew。先克隆仓库：

```sh
git clone https://github.com/Asaki14/dotfiles.git
cd dotfiles
```

预览安装动作，确认后去掉 `--dry-run` 再运行：

```sh
./install.sh --modules rmpc,mpd,beets --dry-run
```

曲库默认放在 `~/Music/lib`。仓库里的 fish 模块带了一个 `ytm` 命令，Agent 加歌时可以直接用：它用 yt-dlp 下载音频和封面，再交给 beets（整理音乐标签的工具）打好标签、放进曲库。菜单栏歌词和主题联动依赖同一仓库里的 omacosy 桌面模块，只想要播放器的话可以不装。

推荐让你的 AI Agent 来帮你配置。
